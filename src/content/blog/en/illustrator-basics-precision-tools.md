## Visual Engineering with Adobe Illustrator

Adobe Illustrator is the industry standard for vector graphics creation. In this tutorial, we address the most basic aspects of the program from a **professional production** perspective, focusing on the work environment and the tools that allow you to take the first steps with technical mastery.

Illustrator, developed by Adobe, is a vector graphics editor used for digital art illustration and graphic design, among other purposes.

It is common to receive requests for promoting events, activities, and invitations. The preparation of these graphic pieces falls on us, and although some "easy-to-use" programs exist, the results are simply not comparable to those achieved with Illustrator.

## 1. Interface and Workspace

To operate with efficiency, it is essential to configure the environment: **Windows -> Workspace -> Essentials Classic**. The order in the panel is a reflection of the order in the design strategy.

![Illustrator CC 2023 Workspace Configuration](https://res.cloudinary.com/flaex/image/upload/v1696958560/strapi-v4/illustrator_basico_workspace_ed2e6fd9d7.png)
_Illustrator CC 2023 Workspace Configuration_

## 2. Create a New Document

We can create a new document via the menu **File -> New**, by clicking the blue "New File" button on the interface, or by pressing **Ctrl + N** (Cmd + N on macOS):

![New Document Assistant in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958559/strapi-v4/illustrator_basico_documento_nuevo_c6e40c8cc3.png)

## 3. Basic Tools

All the tools in this section can be selected using a specific keyboard shortcut, which saves time by avoiding the need to click them manually with the mouse pointer.

![Illustrator CC 2023 User Interface](https://res.cloudinary.com/flaex/image/upload/v1696959604/strapi-v4/illustrator_ui_4aa054ce75.png)
_Illustrator CC 2023 User Interface_

### Selection Tool

This is the main selection tool and is used to select or move any element in the workspace. Shortcut: **V**.

![Main Selection Tool in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958560/strapi-v4/illustrator_basico_seleccion_principal_d34ee246a6.png)
_Main Selection Tool in Illustrator CC 2023_

### Direct Selection Tool

With this tool, you can select a specific part of a shape, one of its anchor points, or a specific object within a group. Shortcut: **A**.

![Direct Selection Tool in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958560/strapi-v4/illustrator_basico_seleccion_directa_41d3dc0c9d.png)
_Direct Selection Tool in Illustrator CC 2023_

### Bézier (Pen Tool)

The Bézier pen tool allows us to create vector paths and shapes exactly as we want. Shortcut: **P**.

![Bézier Pen Tool in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958559/strapi-v4/illustrator_basico_bezier_5a6d3aae7f.png)
_Bézier Pen Tool in Illustrator CC 2023_

### Type Tool

The Type tool allows us to create text boxes to input textual information. Shortcut: **T**.

![Type Tool in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958560/strapi-v4/illustrator_basico_texto_75401eb7f5.png)
_Type Tool in Illustrator CC 2023_

### Rectangle Tool

This tool allows us to quickly create basic geometric shapes. Shortcut: **M**.

![Rectangle Tool in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696960635/strapi-v4/illustrator_basico_rectangulo_bfa42ac9eb.png)
_Rectangle Tool in Illustrator CC 2023_

### Zoom Tool (Magnifying Glass)

The Zoom tool allows us to zoom in or out of the workspace viewing area. Shortcut: **Z**.

![Zoom Tool in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958559/strapi-v4/illustrator_basico_lupa_669c227cad.png)
_Zoom Tool in Illustrator CC 2023_

## 4. Basic Panels

### Swatches Panel

Here we can select from a series of predefined colors for the shapes we create.

![Swatches Panel in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958559/strapi-v4/illustrator_basico_panel_muestra_62a16e441b.png)
_Swatches Panel in Illustrator CC 2023_

### Stroke Panel

Allows us to modify the appearance of paths, such as weight, caps, corner types, and dashes.

![Stroke Panel in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958560/strapi-v4/illustrator_basico_panel_trazo_34f5e844e4.png)
_Stroke Panel in Illustrator CC 2023_

### Layers Panel

In this panel, we manage the stacking order of layers to better organize the elements in our workspace.

![Layers Panel in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958559/strapi-v4/illustrator_basico_panel_capas_c10f50fcb5.png)
_Layers Panel in Illustrator CC 2023_

### Character Panel

Where we configure text settings, such as font family, style, size, leading, tracking, and kerning.

![Character Panel in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958559/strapi-v4/illustrator_basico_panel_character_30f28d2fc4.png)
_Character Panel in Illustrator CC 2023_

### Paragraph Panel

Here we change paragraph layouts, including alignment, indentation, spacing before and after, and hyphenation.

![Paragraph Panel in Illustrator CC 2023](https://res.cloudinary.com/flaex/image/upload/v1696958560/strapi-v4/illustrator_basico_panel_paragraph_f05bba7570.png)
_Paragraph Panel in Illustrator CC 2023_

## Conclusion: The First Step to Mastery

Mastering these tools is the first step to stop using "easy-to-use" programs and start producing professional results with **technical precision and visual authority**.
